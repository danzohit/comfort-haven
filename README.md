# Comfort Haven website

Static website for Comfort Haven, Ikeja, Lagos, Nigeria.

## Publish using GitHub Pages
1. Create a public GitHub repository, e.g. `comfort-haven`.
2. Upload `index.html` and the entire `assets/` folder into the repository root. Do not upload only the ZIP.
3. Commit the files to the `main` branch.
4. Open repository Settings > Pages.
5. Under Build and deployment, choose `Deploy from a branch`, branch `main`, folder `/ (root)`, and Save.
6. Visit `https://danzohit.github.io/comfort-haven/` after deployment finishes.
